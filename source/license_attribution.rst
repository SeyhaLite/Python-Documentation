បានធ្វើឡើងចំពោះឯកសារដើម៖

#. **ភាសា** — មាតិកាទាំងអស់ត្រូវបានសរសេរឡើងវិញជាភាសាខ្មែរ។

   មកបកប្រែពាក្យម្ដងមួយៗទេ។ ការពន្យល់ និងឧទាហរណ៍ត្រូវបានសរសេរ

   CPython 3.15.0 ដើម្បីធានាថាវាដំណើរការពិតប្រាកដ។

   ៦ ដែលខុសពីការបែងចែករបស់ឯកសារដើម។

   parameter និង API ទាំងអស់នៅដូចដើមជាភាសាអង់គ្លេស។

#. **ការរៀបចំគេហទំព័រ** — Sphinx configuration, stylesheet

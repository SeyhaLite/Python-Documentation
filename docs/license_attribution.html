  1. ភាសា — មាតិកាទាំងអស់ត្រូវបានសរសេរឡើងវិញជាភាសាខ្មែរ។ នេះ មិនមែន ជាការបកប្រែដោយម៉ាស៊ីន ឬការចម្លងអត្ថបទអង់គ្លេស មកបកប្រែពាក្យម្ដងមួយៗទេ។ ការពន្យល់ និងឧទាហរណ៍ត្រូវបានសរសេរ ឡើងវិញដើម្បីឱ្យសមស្របនឹងអ្នកអានខ្មែរ។

  2. វិសាលភាពត្រូវបានកាត់បន្ថយ — មានតែជំពូកដែលរាយក្នុង ស្ថានភាពនៃការបកប្រែ ប៉ុណ្ណោះដែលមាន។ Library Reference, Language Reference, C API, Extending/Embedding និង What's New មិនទាន់ត្រូវបានប៉ះពាល់ទេ។

  3. ឧទាហរណ៍កូដត្រូវបានសរសេរឡើងវិញ — ឧទាហរណ៍ទាំងអស់ត្រូវបាន បង្កើតឡើងដោយគម្រោងនេះ ហើយត្រូវបានដំណើរការផ្ទៀងផ្ទាត់លើ CPython 3.15.0 ដើម្បីធានាថាវាដំណើរការពិតប្រាកដ។

  4. រចនាសម្ព័ន្ធត្រូវបានរៀបចំឡើងវិញ — មាតិកាត្រូវបានរៀបចំជាជំពូក ៦ ដែលខុសពីការបែងចែករបស់ឯកសារដើម។

  5. មិនបកប្រែកូដ — ពាក្យគន្លឹះ Python, ឈ្មោះ function, class, module, parameter និង API ទាំងអស់នៅដូចដើមជាភាសាអង់គ្លេស។

  6. ការបន្ថែមមូលដ្ឋាន — ការពន្យល់បន្ថែមអំពីអក្សរខ្មែរ (encoding, len(), isnumeric()) ត្រូវបានបន្ថែមដោយសារពួកវាពាក់ព័ន្ធ ជាពិសេសសម្រាប់អ្នកអានខ្មែរ។

  7. ការរៀបចំគេហទំព័រ — Sphinx configuration, stylesheet (source/_static/khmer.css), templates, ការផ្ទុកពុម្ពអក្សរខ្មែរ និង ប៊ូតុងប្ដូរពណ៌ គឺជាការងារដើមរបស់គម្រោងនេះ រក្សាសិទ្ធិក្រោម MIT License (មើល LICENSE-CODE)។

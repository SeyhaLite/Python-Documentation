Iterators និង Generators

ជំពូកនេះពន្យល់អំពី iteration protocol — យន្តការដែលធ្វើឱ្យ for x in y: ដំណើរការ — និងអំពី generator ដែលជាវិធីសាមញ្ញបំផុត ក្នុងការបង្កើត iterator។

Iteration Protocol

នៅពីក្រោយរង្វិលជុំ for Python ធ្វើការពីរជំហាន៖

  1. ហៅ iter(y) ដើម្បីទទួល iterator object

  2. ហៅ next() លើ iterator នោះម្ដងហើយម្ដងទៀត រហូតដល់វាបញ្ចេញ StopIteration

 1>>> s = "abc"
 2>>> it = iter(s)
 3>>> next(it)
 4'a'
 5>>> next(it)
 6'b'
 7>>> next(it)
 8'c'
 9>>> next(it)
10Traceback (most recent call last):
11  ...
12StopIteration

រង្វិលជុំ for char in s: គឺស្មើនឹង៖

1it = iter(s)
2while True:
3    try:
4        char = next(it)
5    except StopIteration:
6        break
7    print(char)

Note

for loop ចាប់យក StopIteration ដោយស្វ័យប្រវត្តិ។ នេះជា ករណីមួយក្នុងចំណោមករណីមិនច្រើនទេដែល Python ប្រើ exception ជា ផ្នែកធម្មតានៃ control flow។

Iterable ធៀបនឹង Iterator

នេះជាភាពខុសគ្នាសំខាន់បំផុតដែលមនុស្សជាច្រើនច្រឡំ៖

Iterable

Iterator

ត្រូវមាន

__iter__()

__iter__() និង __next__()

អាចដើរលើបានច្រើនដង?

✅ បាទ/ចាស

❌ ទេ — ដើរបានតែ ម្ដង

ឧទាហរណ៍

list, str, tuple, dict, set, range

iter(list), generator, file object, enumerate object

ទទួលបានដោយ

សរសេរផ្ទាល់

iter(iterable)

 
 1>>> nums = [1, 2, 3]
 2>>> it = iter(nums)
 3>>> list(it)              # ប្រើអស់ហើយ
 4[1, 2, 3]
 5>>> list(it)              # ❌ ទទេ — iterator ដើរបានតែម្ដង
 6[]
 7>>> list(nums)            # ✅ list ដើមនៅតែដើរបានច្រើនដង
 8[1, 2, 3]
 9
10>>> iter(nums) is nums            # list មិនមែនជា iterator ទេ
11False
12>>> it = iter(nums)
13>>> iter(it) is it                # iterator ត្រឡប់ខ្លួនឯង
14True

Warning

ភាពខុសគ្នានេះបង្កើត bug ស្ងាត់៖

1>>> data = (x * 2 for x in range(3))    # generator expression — ខ្ជិល
2>>> sum(data)
36
4>>> sum(data)                            # ❌ 0 — អស់ហើយ!
50

បើអ្នកត្រូវការដើរលើទិន្នន័យច្រើនដង សូមប្រើ list ឬហៅ generator function ម្ដងទៀត។

ការបង្កើត Iterator ផ្ទាល់ខ្លួន

 1class Countdown:
 2    """រាប់ថយក្រោយពី start ដល់ 1។"""
 3
 4    def __init__(self, start):
 5        self.start = start
 6        self.current = start
 7
 8    def __iter__(self):
 9        return self                    # ខ្លួនឯងជា iterator
10
11    def __next__(self):
12        if self.current <= 0:
13            raise StopIteration
14        self.current -= 1
15        return self.current + 1

1>>> for n in Countdown(3):
2...     print(n, end=" ")
3...
43 2 1
5>>> c = Countdown(2)
6>>> next(iter(c))
72
8>>> list(c)                            # ដើរបានតែម្ដង
9[1]

Important

__next__() ត្រូវតែ បញ្ចេញ StopIteration នៅពេលអស់ទិន្នន័យ។ បើវាត្រឡប់ None ឬបន្តរហូត រង្វិលជុំ for នឹងមិនឈប់ទេ។

iter() ជាមួយ Sentinel

iter(callable, sentinel) ហៅ callable រហូតដល់វាត្រឡប់ sentinel៖

1>>> from pathlib import Path
2>>> Path("data.bin").write_bytes(b"AB\x00CD")
35
4>>> with open("data.bin", "rb") as f:
5...     chunks = list(iter(lambda: f.read(2), b""))
6...
7>>> chunks
8[b'AB', b'\x00C', b'D']

នេះមានប្រយោជន៍សម្រាប់អានឯកសារ ឬទិន្នន័យបណ្ដាញជាដុំៗ។

Generators

Generator គឺជាវិធីសាមញ្ញបំផុតក្នុងការបង្កើត iterator។ អ្នកសរសេរវា ដូចអនុគមន៍ធម្មតា ប៉ុន្តែប្រើ yield ជំនួស return៖

1def countdown(n):
2    """រាប់ថយក្រោយពី n ដល់ 1។"""
3    print("ចាប់ផ្ដើម")
4    while n > 0:
5        yield n
6        n -= 1
7    print("ចប់")

 1>>> gen = countdown(3)
 2>>> gen                      # មិនទាន់ដំណើរការទេ!
 3<generator object countdown at 0x...>
 4>>> next(gen)
 5ចាប់ផ្ដើម
 63
 7>>> next(gen)
 82
 9>>> next(gen)
101
11>>> next(gen)
12ចប់
13Traceback (most recent call last):
14  ...
15StopIteration

Generator ជា Lazy

អ្វីដែលមាននៅក្នុង generator function មិនដំណើរការទេ រហូតដល់មាន ការហៅ next()។ ហើយវាឈប់នៅត្រង់ yield រួច ចងចាំ ស្ថានភាព ទាំងអស់ (អថេរ local, ទីតាំងកូដ) រហូតដល់ការហៅបន្ទាប់។

 1>>> def traced():
 2...     print("A")
 3...     yield 1
 4...     print("B")
 5...     yield 2
 6...     print("C")
 7...
 8>>> g = traced()             # គ្មានអ្វីត្រូវបានបោះពុម្ពទេ
 9>>> next(g)
10A
111
12>>> next(g)
13B
142
15>>> next(g)
16C
17Traceback (most recent call last):
18  ...
19StopIteration

អត្ថប្រយោជន៍អង្គចងចាំ

Generator ផលិតតម្លៃ ម្ដងមួយៗ ដូច្នេះវាមិនត្រូវការផ្ទុកទិន្នន័យទាំងអស់ ក្នុងអង្គចងចាំទេ៖

1>>> import sys
2>>> big_list = list(range(1_000_000))
3>>> big_gen = (x for x in range(1_000_000))
4>>> sys.getsizeof(big_list) > 8_000_000     # រាប់លាន byte
5True
6>>> sys.getsizeof(big_gen) < 300            # តែរាប់រយ byte
7True

ឧទាហរណ៍ជាក់ស្ដែង — អានឯកសារធំដោយមិនផ្ទុកទាំងមូល៖

 1from pathlib import Path
 2
 3Path("big.log").write_text("\n".join(f"line {i}" for i in range(100_000)),
 4                           encoding="utf-8")
 5
 6
 7def errors_only(path):
 8    """ផលិតតែបន្ទាត់ដែលមានពាក្យ ERROR។"""
 9    with open(path, encoding="utf-8") as f:
10        for line in f:                    # អានម្ដងមួយបន្ទាត់
11            if "ERROR" in line:
12                yield line.rstrip()
13
14
15count = sum(1 for _ in errors_only("big.log"))   # គ្មាន list ក្នុងអង្គចងចាំ

Generator Pipeline

Generator អាចត្រូវបាន តភ្ជាប់ គ្នាដូចបំពង់ — ទិន្នន័យហូរកាត់ម្ដងមួយធាតុ៖

 1def read_lines(path):
 2    with open(path, encoding="utf-8") as f:
 3        for line in f:
 4            yield line.rstrip()
 5
 6
 7def filter_errors(lines):
 8    for line in lines:
 9        if "ERROR" in line:
10            yield line
11
12
13def extract_messages(lines):
14    for line in lines:
15        yield line.split("ERROR", 1)[1].strip()
16
17
18pipeline = extract_messages(filter_errors(read_lines("big.log")))

1>>> sum(1 for _ in pipeline)
20

Note

Pipeline នេះ មិនអានឯកសារទេ រហូតដល់មានការទាញយកតម្លៃដំបូង។ ហើយវាប្រើអង្គចងចាំតែប៉ុន្មានបន្ទាត់ប៉ុណ្ណោះ ទោះបីជាឯកសារមាន រាប់លានបន្ទាត់ក៏ដោយ។ នេះជាគុណសម្បត្តិធំបំផុតរបស់ generator។

Generator គ្មានទីបញ្ចប់

Generator អាចផលិតលំដាប់គ្មានទីបញ្ចប់បាន ព្រោះវាផលិតតាមតម្រូវការ៖

 1>>> def natural_numbers(start=1):
 2...     n = start
 3...     while True:
 4...         yield n
 5...         n += 1
 6...
 7>>> import itertools
 8>>> list(itertools.islice(natural_numbers(), 5))
 9[1, 2, 3, 4, 5]
10>>> list(itertools.islice(natural_numbers(100), 3))
11[100, 101, 102]

Warning

កុំសរសេរ list(natural_numbers()) — វានឹងព្យាយាមផ្ទុកលេខគ្មានទីបញ្ចប់ ហើយអស់អង្គចងចាំ។ ប្រើ itertools.islice() ដើម្បីយកតែចំនួនកំណត់។

yield from

yield from បញ្ជូនតម្លៃទាំងអស់ពី iterable ឬ generator ផ្សេងទៀត៖

 1>>> def flatten(nested):
 2...     for item in nested:
 3...         if isinstance(item, list):
 4...             yield from flatten(item)     # បញ្ជូនបន្តជា recursion
 5...         else:
 6...             yield item
 7...
 8>>> list(flatten([1, [2, [3, 4]], 5]))
 9[1, 2, 3, 4, 5]
10
11>>> def chained():
12...     yield from [1, 2]
13...     yield from (3, 4)
14...     yield from "ab"
15...
16>>> list(chained())
17[1, 2, 3, 4, 'a', 'b']

yield from x ខ្លីជាង៖

1for item in x:
2    yield item

ប៉ុន្តែវាខ្លាំងជាង ព្រោះវាក៏បញ្ជូន send(), throw() និង close() ទៅ generator រងផងដែរ។

Generator Expression

Generator expression ដូច list comprehension ប៉ុន្តែប្រើវង់ក្រចកមូល ( ) ជំនួសវង់ក្រចកការ៉េ [ ]៖

 1>>> squares_list = [x ** 2 for x in range(5)]     # list — ផ្ទុកភ្លាម
 2>>> squares_gen = (x ** 2 for x in range(5))      # generator — ខ្ជិល
 3>>> squares_list
 4[0, 1, 4, 9, 16]
 5>>> squares_gen
 6<generator object <genexpr> at 0x...>
 7>>> list(squares_gen)
 8[0, 1, 4, 9, 16]
 9>>> list(squares_gen)                             # អស់ហើយ
10[]

Tip

នៅពេលបញ្ជូន generator expression ជា argument តែមួយគត់ អ្នកអាចលុប វង់ក្រចកមួយជាន់៖

1>>> sum(x ** 2 for x in range(5))       # គ្មានវង់ក្រចកពីរជាន់
230
3>>> max(len(w) for w in ["a", "bbb", "cc"])
43
5>>> any(x > 2 for x in [1, 2, 3])
6True
7>>> all(x > 0 for x in [1, 2, 3])
8True

នេះមានប្រសិទ្ធភាពជាង sum([x ** 2 for x in range(5)]) ព្រោះវា មិនបង្កើត list កណ្ដាលទេ។

send(), throw() និង close()

Generator អាច ទទួល តម្លៃពីខាងក្រៅបានផងដែរ (coroutine)៖

 1>>> def accumulator():
 2...     total = 0
 3...     while True:
 4...         value = yield total        # ទទួលតម្លៃ ហើយបញ្ជូន total ចេញ
 5...         if value is None:
 6...             break
 7...         total += value
 8...
 9>>> acc = accumulator()
10>>> next(acc)                          # ចាប់ផ្ដើម (prime the generator)
110
12>>> acc.send(10)
1310
14>>> acc.send(5)
1515
16>>> acc.close()                        # បញ្ឈប់

Method

ឥទ្ធិពល

next(g) ឬ g.send(None)

ដំណើរការបន្ត រហូតដល់ yield បន្ទាប់

g.send(value)

ដំណើរការបន្ត ហើយធ្វើឱ្យ yield ត្រឡប់ value

g.throw(exc)

បញ្ចេញ exception នៅត្រង់ yield បច្ចុប្បន្ន

g.close()

បញ្ចេញ GeneratorExit ខាងក្នុង · generator ត្រូវបញ្ចប់

Important

អ្នក ត្រូវតែ ហៅ next(g) (ឬ g.send(None)) មុន send() លើកដំបូង ព្រោះ generator មិនទាន់ដំណើរការដល់ yield ដំបូងទេ។ បើមិនដូច្នោះ អ្នកនឹងទទួល TypeError។

Note

close() បញ្ចេញ GeneratorExit នៅត្រង់ yield។ Generator អាច ចាប់យកវាដើម្បីសម្អាតធនធាន ប៉ុន្តែ មិនអាច yield បន្ទាប់ពីនោះទេ — វានឹងបញ្ចេញ RuntimeError។

សម្រាប់ការសម្អាតធនធាន វិធីសាមញ្ញបំផុតគឺប្រើ try/finally ក្នុង generator៖

1def read_rows(path):
2    f = open(path, encoding="utf-8")
3    try:
4        for line in f:
5            yield line.rstrip()
6    finally:
7        f.close()          # ដំណើរការទោះបី generator ត្រូវបាន close()

return ក្នុង Generator

return value ក្នុង generator បញ្ចប់វា ហើយដាក់ value ទៅក្នុង StopIteration.value៖

 1>>> def gen_with_return():
 2...     yield 1
 3...     yield 2
 4...     return "លទ្ធផលចុងក្រោយ"
 5...
 6>>> g = gen_with_return()
 7>>> next(g), next(g)
 8(1, 2)
 9>>> try:
10...     next(g)
11... except StopIteration as e:
12...     print("StopIteration.value =", e.value)
13...
14StopIteration.value = លទ្ធផលចុងក្រោយ

yield from ចាប់យកតម្លៃនេះដោយស្វ័យប្រវត្តិ៖

1>>> def wrapper():
2...     result = yield from gen_with_return()
3...     print("ទទួលបានពី sub-generator:", result)
4...
5>>> list(wrapper())
6ទទួលបានពី sub-generator: លទ្ធផលចុងក្រោយ
7[1, 2]

 2>>> list(itertools.chain([1, 2], "ab"))

1>>> list(itertools.batched("ABCDEFG", 3))
2[('A', 'B', 'C'), ('D', 'E', 'F'), ('G',)]

Warning

groupby() ក្រុមតែធាតុ ជាប់គ្នា ប៉ុណ្ណោះ។ អ្នកត្រូវតម្រៀបទិន្នន័យ តាម key ជាមុន៖

1>>> data = [("b", 1), ("a", 2), ("b", 3)]
2>>> # ❌ 'b' ពីរក្រុម
3>>> [(k, len(list(g))) for k, g in itertools.groupby(data, key=lambda t: t[0])]
4[('b', 1), ('a', 1), ('b', 1)]
5>>> data_sorted = sorted(data, key=lambda t: t[0])
6>>> # ✅
7>>> [(k, len(list(g))) for k, g in itertools.groupby(data_sorted, key=lambda t: t[0])]
8[('a', 1), ('b', 2)]

ចំណាំថា groupby() ត្រូវបាន ប្រើប្រាស់ភ្លាម — បើអ្នកមិនបំលែង sub-iterator g ទៅ list មុនពេលដើរទៅក្រុមបន្ទាប់ វានឹងទទេ។

Tip

ជ្រើសរើស generator ពេលណា?

  • ទិន្នន័យធំ ឬគ្មានទីបញ្ចប់ → generator

  • ដើរលើទិន្នន័យតែម្ដង (ឧ. pipeline) → generator

  • ត្រូវការ index, ប្រវែង ឬដើរច្រើនដង → list

  • ទិន្នន័យតូចហើយច្បាស់ → list (សាមញ្ញជាង)

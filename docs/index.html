ឯកសារ Python ជាភាសាខ្មែរ

កំណែ Python ដែលឯកសារនេះយោង

មាតិកាទាំងអស់សរសេរសម្រាប់ Python 3.15 (កំណែ stable ចេញថ្ងៃ ៩ តុលា ២០២៦)។ ឧទាហរណ៍កូដនីមួយៗត្រូវបានដំណើរការផ្ទៀងផ្ទាត់ជាក់ស្ដែងលើ CPython 3.15.0។ Python 2 មិនត្រូវបានគាំទ្រទេ — សូមកុំប្រើវា។

សូមស្វាគមន៍មកកាន់ឯកសារបង្រៀនភាសា Python ជាភាសាខ្មែរ។ គម្រោងនេះយោងតាម ឯកសារផ្លូវការរបស់ CPython ក្នុងថត Doc/ (Doc/tutorial/, Doc/using/ និង Doc/library/) ហើយសរសេរឡើងវិញជាភាសាខ្មែរដើម្បីឱ្យអ្នកសិក្សាខ្មែរងាយយល់។

គោលការណ៍សំខាន់ពីរដែលយើងរក្សាជានិច្ច៖

  1. ពាក្យបច្ចេកទេស និងកូដមិនបកប្រែទេ។ ពាក្យគន្លឹះដូចជា if, for, while, def, class, import, return, True, False, None ឈ្មោះ function, class, module និង parameter ទាំងអស់នៅដូចដើម ជាភាសាអង់គ្លេស។ មានតែការពន្យល់ប៉ុណ្ណោះដែលជាភាសាខ្មែរ។

  2. ឧទាហរណ៍កូដត្រូវតែដំណើរការពិត។ គ្មាន API ដែលស្មានចិត្ត ឬបង្កើតឡើងទេ។

តើអ្នកគួរចាប់ផ្ដើមពីណា?

បើអ្នកមិនទាន់ដំឡើង Python ទេ សូមចាប់ផ្ដើមពី ចាប់ផ្ដើម និងការដំឡើង Python។ បើអ្នកចេះភាសាគម្រោងវការផ្សេងរួចហើយ អ្នកអាចរំលងទៅ វាក្យសម្ពន្ធ អថេរ និងប្រភេទទិន្នន័យ បានភ្លាម។

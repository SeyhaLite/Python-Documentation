ចាប់ផ្ដើម និងការដំឡើង Python

តើ Python ជាអ្វី?

Python គឺជាភាសាកម្មវិធី (programming language) កម្រិតខ្ពស់ ដែលរចនាឡើងដោយ លោក Guido van Rossum នៅដើមទសវត្សរ៍ ១៩៩០។ វាលេចធ្លោដោយសារ៖

  • វាក្យសម្ពន្ធសាមញ្ញ — កូដ Python អានដូចអង់គ្លេសសាមញ្ញ ដូច្នេះងាយរៀន និងងាយថែទាំ។

  • រចនាសម្ព័ន្ធទិន្នន័យកម្រិតខ្ពស់មានស្រាប់ — list, dict, set, tuple ដំណើរការលឿន និងមិនចាំបាច់ប្រកាសទំហំជាមុន។

  • បណ្ណាល័យស្តង់ដារ (standard library) ធំ — មានម៉ូឌុលសម្រាប់ឯកសារ, បណ្ដាញ, JSON, ពេលវេលា, regular expression និងច្រើនទៀត ដោយមិនចាំបាច់ ដំឡើងអ្វីបន្ថែម។

  • Interpreted language — អ្នកអាចសាកល្បងកូដភ្លាមៗក្នុង REPL ដោយមិនចាំបាច់ compile ជាមុន។

  • Dynamic typing — អថេរមិនចាំបាច់ប្រកាសប្រភេទ (type) ជាមុនទេ។

Note

Python នៅទីនេះសំដៅលើ Python 3 ប៉ុណ្ណោះ។ Python 2 ត្រូវបានបញ្ឈប់ ការគាំទ្រជាផ្លូវការតាំងពីថ្ងៃទី ១ មករា ២០២០ ហើយមិនទទួលបានការជួសជុល សុវត្ថិភាពទៀតទេ។

ការដំឡើង Python

Windows

មានជម្រើសធំៗពីរ៖

ជម្រើសទី ១ — Installer ផ្លូវការពី python.org (ណែនាំ)

  1. ទៅកាន់ https://www.python.org/downloads/windows/ ហើយទាញយកកំណែ Windows installer (64-bit) ចុងក្រោយ។

  2. ដំណើរការឯកសារ .exe ដែលបានទាញយក។

  3. សំខាន់បំផុត៖ ក្នុងអេក្រង់ដំបូង សូមធីកប្រអប់ Add python.exe to PATH មុនចុច Install Now។ បើអ្នកភ្លេចធីក ពាក្យបញ្ជា python នឹងមិនដំណើរការក្នុង Command Prompt ទេ។

ជម្រើសទី ២ — Microsoft Store

ស្វែងរក "Python" ក្នុងកម្មវិធី Microsoft Store ហើយចុច Get។ វិធីនេះងាយ បំផុត ហើយធ្វើបច្ចុប្បន្នភាពដោយស្វ័យប្រវត្តិ ប៉ុន្តែមានដែនកំណត់មួយចំនួន លើការចូលដំណើរការឯកសារក្រៅផ្ទះរបស់អ្នក។

ការផ្ទៀងផ្ទាត់

បើក Command Prompt (cmd) ឬ PowerShell ហើយវាយ៖

1C:\> py -V
2Python 3.15.0
3
4C:\> python --version
5Python 3.15.0

នៅលើ Windows ពាក្យបញ្ជា py គឺជា Python launcher ដែលអនុញ្ញាតឱ្យ អ្នកជ្រើសរើសកំណែជាក់លាក់បាន ឧទាហរណ៍ py -3.13 ឬ py -3.15។

macOS

Installer ផ្លូវការ (ណែនាំ)

  1. ទៅ https://www.python.org/downloads/macos/ ហើយទាញយកឯកសារ macOS 64-bit universal2 installer។

  2. ដំណើរការឯកសារ .pkg ហើយដើរតាមជំហានរហូតដល់ចប់។

  3. បន្ទាប់ពីដំឡើងរួច សូមដំណើរការឯកសារ Install Certificates.command ដែលនៅក្នុងថត /Applications/Python 3.15/។ ជំហាននេះដំឡើងវិញ្ញាបនបត្រ SSL ដែល pip និង urllib ត្រូវការ ដើម្បីភ្ជាប់ទៅគេហទំព័រ HTTPS។

Homebrew

1$ brew install python@3.15

Attention

នៅលើ macOS ពាក្យបញ្ជា python (គ្មានលេខ ៣) អាចសំដៅលើ Python ចាស់ របស់ប្រព័ន្ធ ឬមិនមានសោះ។ សូមប្រើ python3 ជានិច្ច។

1$ python3 --version

REPL — របៀប Interactive

REPL (Read–Eval–Print Loop) គឺជាម៉ូដអន្តរកម្ម ដែល Python អានបន្ទាត់កូដ ដំណើរការវា បោះពុម្ពលទ្ធផល ហើយរង់ចាំបន្ទាត់បន្ទាប់។ វាល្អបំផុតសម្រាប់សាកល្បង គំនិតតូចៗ និងរៀនភាសា។

1>>> 2 + 3
25
3>>> "Python" * 2
4'PythonPython'
5>>> name = "ខ្មែរ"
6>>> print(f"សួស្ដី {name}!")
7សួស្ដី ខ្មែរ!

សញ្ញា prompt ពីរប្រភេទ៖

Prompt

អត្ថន័យ

>>>

Primary prompt — រង់ចាំបន្ទាត់កូដថ្មី (statement ពេញលេញ)។

...

Secondary prompt — បន្តបន្ទាត់នៃ block ដែលមិនទាន់ចប់ (ឧ. ខ្លួន if, for, def)។

ចេញពី REPL ដោយ៖

  • Unix / Linux / macOS — ចុច Control-D

  • Windows — ចុច Control-Z រួច Enter

  • គ្រប់ប្រព័ន្ធ — វាយ quit() ឬ exit()

Indentation គឺចាំបាច់

Python ប្រើ ការចូលបន្ទាត់ (indentation) ដើម្បីកំណត់ block ជំនួសឱ្យ វង់ក្រចក {} ឬពាក្យ begin/end។ នៅក្នុង REPL អ្នកត្រូវចុច Enter ទទេម្ដងទៀតដើម្បីបញ្ចប់ block៖

1>>> for i in range(3):
2...     print(i, end=" ")
3...
40 1 2

Warning

ប្រើ ដកឃ្លា (space) ៤ សម្រាប់ indentation ជានិច្ច កុំលាយឡំជាមួយ tab។ ការលាយឡំបណ្ដាលឱ្យមាន IndentationError ឬ TabError ដែលពិបាកមើលឃើញ។ កំណត់ editor របស់អ្នកឱ្យបំលែង tab ទៅជា space ៤។

ការដំណើរការ Script

ដាក់កូដក្នុងឯកសារដែលមានផ្នែកបន្ថែម .py ឧទាហរណ៍ hello.py៖

hello.py
1"""Script ដំបូង — បោះពុម្ពសារ និងធ្វើគណនាសាមញ្ញ។"""
2
3print("សួស្ដីពី Python 3.15!")
4print("ផលបូក 1 + 2 =", 1 + 2)

ដំណើរការវា៖

1$ python3 hello.py
2សួស្ដីពី Python 3.15!
3ផលបូក 1 + 2 = 3

ជម្រើសបន្ទាត់ពាក្យបញ្ជាដែលសំខាន់

ពាក្យបញ្ជា

ការប្រើប្រាស់

python3 script.py

ដំណើរការឯកសារ script។

python3 -c "code"

ដំណើរការកូដដែលបានវាយផ្ទាល់។ ដាក់កូដក្នុងសញ្ញាសម្រង់ជានិច្ច។

python3 -m module

ដំណើរការម៉ូឌុលជា script ឧ. python3 -m json.tool ឬ python3 -m venv .venv។

python3 -i script.py

ដំណើរការ script រួចបន្តចូល REPL ដើម្បីពិនិត្យអថេរ។

python3 -V

បោះពុម្ពកំណែ Python។

python3 -h

បង្ហាញជម្រើសទាំងអស់។

ឧទាហរណ៍ជាក់ស្ដែង៖

1$ python3 -c "import platform; print(platform.python_version())"
23.15.0
3
4$ python3 -m this | head -3
5The Zen of Python, by Tim Peters
6
7Beautiful is better than ugly.

Shebang នៅលើ Unix

ដើម្បីដំណើរការ script ដោយផ្ទាល់ (./hello.py) សូមដាក់បន្ទាត់ដំបូងជា shebang៖

1#!/usr/bin/env python3

រួចផ្ដល់សិទ្ធិប្រតិបត្តិ៖

1$ chmod +x hello.py
2$ ./hello.py
3សួស្ដីពី Python 3.15!

វិធី /usr/bin/env python3 ល្អជាង /usr/bin/python3 ព្រោះវាស្វែងរក Python ក្នុង PATH របស់អ្នកប្រើ។

ការទទួល Argument ពីបន្ទាត់ពាក្យបញ្ជា

Argument ទាំងអស់ត្រូវបានដាក់ក្នុង list ឈ្មោះ sys.argv។ ធាតុដំបូង sys.argv[0] គឺឈ្មោះ script ខ្លួនឯង។

argv_demo.py
 1"""បង្ហាញរបៀបទទួល argument ពីបន្ទាត់ពាក្យបញ្ជាតាម sys.argv។"""
 2
 3import sys
 4
 5print(sys.argv)
 6
 7args = sys.argv[1:]
 8print("ចំនួន argument (មិនរាប់ឈ្មោះឯកសារ):", len(args))
 9
10if args:
11    print("argument ដំបូង:", args[0])

1$ python3 argv_demo.py សុខា ដារ៉ា
2['argv_demo.py', 'សុខា', 'ដារ៉ា']
3ចំនួន argument (មិនរាប់ឈ្មោះឯកសារ): 2
4argument ដំបូង: សុខា

Encoding — UTF-8 ជាលំនាំដើម

ចាប់តាំងពី Python 3 មក ឯកសារប្រភព (.py) ត្រូវបានអានជា UTF-8 ជាលំនាំដើម។ ដូច្នេះអ្នកអាចប្រើអក្សរខ្មែរក្នុងខ្សែអក្សរ (string) និងក្នុង អត្ថាធិប្បាយ (comment) បានដោយសេរី៖

1>>> greeting = "សួស្ដី ពិភពលោក"
2>>> len(greeting)                 # ១៤ តួអក្សរ (រួមទាំងដកឃ្លាមួយ)
314
4>>> len(greeting.encode("utf-8")) # ៤០ byte
540
6>>> greeting[0]
7'ស'

Note

len() រាប់ចំនួន តួអក្សរ (character) មិនមែនចំនួន byte ទេ។ អក្សរខ្មែរមួយត្រូវការ ៣ byte ក្នុង UTF-8 ប៉ុន្តែរាប់ជា ១ តួអក្សរ។ ចំណាំថា ស្រៈ និងជើងអក្សរខ្មែរក៏រាប់ជាតួអក្សរដាច់ដោយឡែកដែរ — ពាក្យ "សួស្ដី" មាន ៦ តួអក្សរ មិនមែន ៥ ទេ។ បើអ្នកចង់ដឹងចំនួន byte ប្រើ len(greeting.encode("utf-8"))។

ពេលអានឬសរសេរឯកសារ សូមបញ្ជាក់ encoding="utf-8" ជាច្បាស់លាស់ជានិច្ច (មើលជំពូក ការគ្រប់គ្រងឯកសារ) ព្រោះលំនាំដើមអាចខុសគ្នាតាមប្រព័ន្ធ ប្រតិបត្តិការ។

កម្មវិធីដំបូងរបស់អ្នក

សូមសរសេរឯកសារ first.py ដូចខាងក្រោម៖

first.py
1"""កម្មវិធីដំបូង — ទទួលទិន្នន័យពីអ្នកប្រើ រួចបោះពុម្ពត្រឡប់វិញ។"""
2
3name = input("សូមបញ្ចូលឈ្មោះរបស់អ្នក: ")
4age = int(input("សូមបញ្ចូលអាយុរបស់អ្នក: "))
5
6print(f"សួស្ដី {name}! អ្នកមានអាយុ {age} ឆ្នាំ។")
7print(f"ក្នុងរយៈពេល ៥ ឆ្នាំទៀត អ្នកនឹងមានអាយុ {age + 5} ឆ្នាំ។")

ដំណើរការ៖

1$ python3 first.py
2សូមបញ្ចូលឈ្មោះរបស់អ្នក: សុភា
3សូមបញ្ចូលអាយុរបស់អ្នក: 20
4សួស្ដី សុភា! អ្នកមានអាយុ 20 ឆ្នាំ។
5ក្នុងរយៈពេល ៥ ឆ្នាំទៀត អ្នកនឹងមានអាយុ 25 ឆ្នាំ។

ចំណុចគួរកត់សម្គាល់ពីឧទាហរណ៍នេះ៖

  • input() តែងតែត្រឡប់ជា string ដូច្នេះត្រូវបំលែងទៅ int ដោយ int(...) មុនធ្វើគណនា។

  • f-string (f"...") អនុញ្ញាតឱ្យបញ្ចូលតម្លៃអថេរក្នុងខ្សែអក្សរ ដោយដាក់វាក្នុងវង់ក្រចកដង្កៀប {}។

  • # ចាប់ផ្ដើម comment — Python មិនអានវាទេ។
